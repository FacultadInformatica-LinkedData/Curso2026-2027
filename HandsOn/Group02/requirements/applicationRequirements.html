Application Requirements

1. Application description

Madrid Green Spaces is a web application that allows users to explore the main municipal parks and gardens of Madrid. The application will display parks on a map and provide information about their location, district and characteristics.

2. Functional requirements

  • The user can view the parks and gardens of Madrid on a map.
  • The user can search for a park by name.
  • The user can filter parks by district.
  • The user can select a park to view its details.
  • The user can view the address and geographical location of each park, when available.
  • The application can link park information with other geographical open datasets.

3. Data requirements

The application will use the Main Municipal Parks and Gardens dataset published by the Madrid City Council. The data will be transformed into RDF and linked to other relevant datasets during the course.

The application will use the NOMBRE, DISTRITO, BARRIO, LATITUD, LONGITUD and CONTENT-URL fields. LATITUD and LONGITUD will be used to display the parks on a map. The park names, districts and neighbourhoods will be linked with geographic entities from Wikidata, DBpedia or GeoNames.

5. Expected outcome

The expected outcome is a web application that makes it easier for citizens to discover and explore green spaces in Madrid using open and linked data.
