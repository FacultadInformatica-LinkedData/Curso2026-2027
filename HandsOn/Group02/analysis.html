Analysis of the data source

Group 02 – Hands-on assignment 2. Dataset: Main Municipal Parks and Gardens of Madrid (Madrid City Council).

1. Data set analysis

1.1 General description

  • File: 200761-0-parques-jardines-csv.csv, comma-separated, text fields in double quotes, header in the first row.
  • Size: 208 records (one per park/garden) and 32 columns.
  • Primary key: PK (numeric, 208 distinct values, no duplicates).
  • Language: Spanish (column names and free text).
  • Domain: Smart City / environment (green spaces).
