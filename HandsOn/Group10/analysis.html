Dataset

Description: The dataset Red de Calidad del Aire. Datos meteorológicos horarios desde 2020 is published by the Community of Madrid Open Data Portal. The selected resource is 2026.csv, which contains hourly meteorological measurements collected by the region's air-quality monitoring stations. The selected dataset has 47628 rows and 56 columns.

Data fields

· hxx: floating point numeric value. Includes the value measured for hour xx.

· vxx: includes whether the data for hour xx is validated (V) or not (N). 128 entries have N, 47439 have V

· provincia: includes the number for the province (Madrid). All entries use value 28.

· municipio: includes the number identifying the municipality in a province. Values from 5 to 180. With every value appearing having same frequency as every other value appearing.

· estacion: includes the number identifying the station. Values from 1 to 14.

· magnitud: includes the number identifying type of magnitude measured. Values from 81 to 89. Same frequency for all appearances.

· punto_muestreo: includes the full number that identifies province, municipality, station, magnitude and technique for the measurement.

· ano: year of the measurement.

· mes: month of the measurement.

· dia: day of the measurement.
