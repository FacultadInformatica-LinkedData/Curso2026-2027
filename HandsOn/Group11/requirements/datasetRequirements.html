Dataset Requirements

Dataset: Estaciones de BiciMAD

R1. Data are in one of the selected smart city domains

Yes. The dataset belongs to the mobility and urban transport domain, which is one of the main smart city domains.

R2. Data are available as a CSV file

Yes. The dataset is available in CSV format in the EMT Madrid Open Data Portal.

R3. Data have an open license so they can be published

Yes. The dataset is published under an open Creative Commons Attribution license, which allows reuse and publication as long as the original source is properly attributed.

R4. Data can be easily linked with generic real-world entities

Yes. Each BiciMAD station contains information such as its address, name and geographic coordinates. These data can be linked with real-world entities such as streets, districts, neighbourhoods, etc...

R5. Documentation exists for the data

Yes. The EMT Madrid Open Data Portal provides metadata and documentation describing the dataset and its fields.

R6. Data can come from multiple data sources

Currently, the selected data come from a single source, the EMT Madrid Open Data Portal.

Linkable entities

Entities in the BiciMAD dataset that can be linked with other datasets include stations, addresses, streets and geographic coordinates.

Entities in external datasets that could be linked with the BiciMAD dataset include Madrid streets, neighbourhoods, districts and other geographic entities.
