Application Requirements

Application description

The application will allow users to explore BiciMAD stations in Madrid. Users will be able to search for stations, view their location and access information such as the station name, address, number of total bases and current state.

Main functionalities

  • Display BiciMAD stations on a map.
  • Search stations by name or address.
  • View detailed information about each station.
  • Filter stations by location or area.
  • Show the number of total bases and the station status.

User interface

The main interface will include a map of Madrid with markers for each BiciMAD station. A search bar and filters will allow users to find specific stations. When a station is selected, a panel will display its detailed information.
