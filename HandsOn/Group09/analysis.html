3. Resource Naming Strategy

Following Linked Data best practices and the course guidelines:

  • Domain: http://smartcity.linkeddata.es/bicis/ (independent from Protégé default namespaces).
  • URI form: Hash URIs (#) for ontological definitions (classes and properties) and Slash URIs (/) for dataset individuals/resources.
  • Ontology terms URI: http://smartcity.linkeddata.es/bicis/ontology#
  • Resource individuals base path: http://smartcity.linkeddata.es/bicis/resource/

URI Patterns for Individuals & Terms

Element Pattern Concrete Example
Ontology Class http://smartcity.linkeddata.es/bicis/ontology#[ClassName] http://smartcity.linkeddata.es/bicis/ontology#BicycleParking
Ontology Property http://smartcity.linkeddata.es/bicis/ontology#[propertyName] http://smartcity.linkeddata.es/bicis/ontology#hasCapacity
Bicycle Parking Resource http://smartcity.linkeddata.es/bicis/resource/BicycleParking/[id] http://smartcity.linkeddata.es/bicis/resource/BicycleParking/10001
District Resource http://smartcity.linkeddata.es/bicis/resource/District/[districtName] http://smartcity.linkeddata.es/bicis/resource/District/Centro
Neighborhood Resource http://smartcity.linkeddata.es/bicis/resource/Neighborhood/[neighborhoodName] http://smartcity.linkeddata.es/bicis/resource/Neighborhood/Justicia
