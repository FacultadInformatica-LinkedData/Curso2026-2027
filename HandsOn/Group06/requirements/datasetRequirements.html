2. Requirement assessment

Requirements Bibiliotecas de Madrid Museos de la ciudad de Madrid Evidence and limitations
R1 · Smart-city domain Yes Yes Both data are part of the smart community facilities. Futhermore, libraries data can also be included in smart education and museums data in smart tourism.
R2 · CSV availability Yes Yes Both datasets are available and have been downloaded in CSV format as it can be seen from the csv folder.
R3 · Open license Yes Yes Both datasets are under de CC BY 4.0 license, which gives freedom to share and adapt the material as long appropiate attribution is given.
R4 · Linkable real-world entities Yes Yes LOCALIDAD, COD-DISTRITO / DISTRITO, COD-BARRIO / BARRIO, names, addresses and LATITUD / LONGITUD, which are columns from the datasets, support reconciliation with cities, districts, neighborhoods and facilities.
R5 · Documentation (optional) Fully satisfied Fully satisfied Documentation is available as it is shown in the previous section and can also be download at the bottom of the website from both datasets
R6 · Multiple sources (optional) Partially satisfied Two distinct datasets, but one publishing portal and publisher. Wikidata is a planned external linking source; it is not included as a downloaded input dataset.

3. External entities and linking plan

Local entity / fields External target Matching method
City: LOCALIDAD = MADRID Wikidata Madrid (Q2807) Confirm that the locality denotes the city rather than the autonomous community; link a city resource and relate each facility to that city.
Museum: PK = 2058, NOMBRE = Museo del Prado; coordinates 40.414069291230945, -3.6922134558146453 Wikidata Museo del Prado (Q160112) Match the museum using its name, official website and coordinates.
Districts and neighborhoods: codes plus names Wikidata administrative-area items; optionally DBpedia resources Match by geographic codes and normalized names, using Madrid and the administrative-area type to disambiguate.
Libraries: NOMBRE, address, CONTENT-URL, coordinates Wikidata library items where available Use library names, official websites, addresses and coordinates to match available library items.
