Application Requirements: Madrid Sports Finder

1. General description

Madrid Sports Finder is a web application that helps residents and visitors find places to practise sport in Madrid. It is built on the linked data generated from our three datasets (basic municipal sports facilities, sports centres and swimming pools; see datasetRequirements.html). Users search by sport, district and accessibility, see the results on a map, and consult details of each facility.

2. Users

  • Resident: looks for a free pitch, court or pool close to home.
  • Visitor or newcomer: wants to know what sport facilities exist in a district.
  • User with reduced mobility: needs accessible facilities.

4. Non-functional requirements

  • The data is read from RDF through a SPARQL endpoint or the published linked data, not from CSV files.
  • The interface works on desktop and mobile browsers.
  • Facilities with no opening hours show "Not available" instead of an empty field.
  • Interface in Spanish and English.
