Justificación de los Requisitos del Dataset


Hemos seleccionado un dataset demográfico sobre el porcentaje de población según el ámbito geográfico (Galicia).

Requisitos:

R1. Dominio Smart City:
Cumplido. La distribución y concentración de la población es el parámetro base para la planificación territorial inteligente y el dimensionamiento de infraestructuras críticas. Página web: https://abertos.xunta.gal/catalogo/territorio-vivienda-transporte/-/dataset/0184/indicadores-poboacion
R2. Formato CSV:
Cumplido. Los datos se encuentran en formato .csv.
R3. Licencia Abierta:
Cumplido. Los datos se distribuyen bajo la licencia Creative Commons Reconocimiento-CompartirIgual 4.0 (CC BY-SA 4.0)
R4. Vinculación con entidades reales: El dataset contiene municipios de Galicia identificados mediante su nombre y su código INE. Por ejemplo, Boimorto aparece con el código 15010 y Touro con el código 15085.
    1. Entidades de nuestro dataset:
    Esta tabla contiene el Código INE oficial del municipio (ej. "15006" para Arzúa).
    2. Entidades en otros datasets:
    Estos códigos INE actúan como identificadores unívocos para enlazar las entidades geográficas con Wikidata o DBpedia.
R5. Documentación:
Cumplido parcialmente. El CSV incluye cabeceras que identifican los indicadores, el ámbito geográfico y el año de los datos.
R6. Múltiples fuentes:
No cumplido, ya que por ahora solo hemos incluido un archivo CSV.
