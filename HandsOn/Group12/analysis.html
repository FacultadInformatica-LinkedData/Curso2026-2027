Data Set Analysis


The dataset contains metadata in the first few rows; with actual data starting after the year row (row 7). All information from this file refers to the year 2025. Each Galician municipality starts with a five digit INE code, such as 15006 Arzúa. This is the Espazo column which will be depicted as rdf type: string/Resource. We will be splitting this information into the following:

  • INE code: 15006
  • Municipality name: Arzúa
The file contains five indicators in total:
  1. Porcentaxe de poboación segundo ámbito xeográfico
    This indicates the percentage of the population that corresponds to the municipality. (rdf type: decimal). Below are some of the important values for this indicator:
    • Minimum - 0.38
    • Maximum - 88.77
    • Average - 16.93
  2. Densidade de poboación
    this indicates the population density, measured in inhabitants per km2. (rdf type: decimal). Below are some of the important values for this indicator:
    • Minimum - 2.5
    • Maximum - 6642.3
    • Average -144.93
  3. Porcentaxe de poboación menor de 20 anos
    this indicates the percentage of the population of the municipality that’s under 20. (rdf type: decimal). imal) Below are some of the important values for this indicator:
    • Minimum - 3.25%
    • Maximum - 20.44%
    • Average - 11.70%
  4. Porcentaxe de poboación entre 20 e 64 anos
    this indicates the percentage of the population of the municipality that’s between 20 and 64, inclusive. (rdf type: decimal). Below are some of the important values for this indicator:
    • Minimum - 40.18%
    • Maximum - 64.91%
    • Average - 53.60%
  5. And lastly, Porcentaxe de poboación de 65 e máis anos
    this indicates the percentage of the population that’s 65 and older. (rdf type: decimal). Below are some of the important values for this indicator:
    • Minimum - 14.91%
    • Maximum - 55.86%
    • Average - 34.70%
This file uses the semicolon (;) as an indicator for column separation, while the comma (,) is used for the decimal place. Some columns have empty values (-).This dataset can be represented in RDF type by depicting municipalities as resources and its indicators—the demographic information—as decimal properties.


Schema


Municipality

  • Has INE code
  • Has name
  • Has demographic information
Demographic information
  • Has year
  • Has population percentage
  • Has population density
  • Has population percentage under 20
  • Has population percentage betwen 20 and 64
  • Has population percentage over 65

Resource Naming Strategy


For the generation of the ontology and linked data, a URI naming strategy has been defined to conceptually separate the conceptual model from the instantiated data, using a custom base domain (https://w3id.org/smartinfra-galicia/).

  • Ontology (Classes and Properties): We use the ontology/ path followed by the model name and a hash (#). Properties are defined independently of class URIs.
    Example: https://w3id.org/smartinfra-galicia/ontology/Demographics#Municipality
  • Individuals / Data (Resources): Instantiated data uses the resource/ path, ensuring that paths for ontology resources and individuals are completely different.
  • Independent paths per class: We ensure that paths for individuals of different classes are not the same to avoid collisions.
    • For municipalities: .../resource/municipality/<INE_code> (e.g., 15006)
    • For demographic observations: .../resource/demographicinformation/<INE_code>-<year> (e.g., 15006-2025)
